Refused, and why
Aurora, Spotlight, Lamp, Meteors, Vortex, Wavy, Background Beams, Shooting Stars, Glowing Effect, Background Gradient Animation
Ten variations on one idea: a coloured glow behind a heading. This is the exact family the slop research names — radial spotlight glows, gradient beams, dark mode with a coloured bloom. Adopting any of them undoes the last three rounds.
3D Card, Comet Card, Wobble Card, Draggable Card, Glare Card, 3D Marquee, Container Scroll
Tilt and perspective on a card whose content is somebody’s funding request. Nothing here reads the data better; it reads as a demo.
Typewriter, Text Generate, Encrypted Text, Flip Words, Colourful Text, Squiggly Text, Canvas Text
Text that moves or assembles itself. NN/g’s lower-literacy research says plainly to avoid text that moves or changes — and that is our primary user. Also: animating a disease name into place is grotesque.
3D Globe, GitHub Globe, World Map
A rotating globe on a product serving one country’s smallholders is decoration pretending to be scale.
Following Pointer, Magnetic Button, Gooey Input, Webcam Pixel Grid, ASCII Art, Dither Shader, Cloud Shader, Shaders
Cursor and shader work on a product whose main surface is a 360 px touchscreen with no cursor and a GPU already busy encoding video.
Two that need care rather than refusal
Animated Modal
Fine for a photo or a help panel. Never for investing, harvest reporting or settlement: a money decision needs the evidence visible beside it and a URL someone can return to, and a modal has neither.
Stateful Button
Good for the loading state, dangerous for the success state. It must never flip to a tick before the server has confirmed — optimistic UI on a payout is a lie with money attached.
The cost, which is the real objection

Aceternity is React plus Framer Motion. The farmer budget is 250 KB of JavaScript on a 6.2 Mbps P75 connection. Framer Motion alone is roughly a fifth of that before a single component.

So: none of these six ship to the farmer as a library. Compare, Lens, Timeline and Terminal are desktop-only, where the budget is not the constraint. The Multi Step Loader is the one farmer-facing pick and it is four divs and a width transition — take the pattern, not the dependency.
